# 🎓 Student Result Management System

A web-based **Student Result Management System** developed using **Python and Django**. The project is designed to manage student academic information and other college-related activities through a centralized system.

## 🚀 Features

* 👨‍🎓 Student Management
* 👨‍🏫 Teacher Management
* 📊 Student Result Management
* 📝 Attendance Management
* 💰 Fee Management
* 📢 Notice Management
* 🪪 Student ID Card
* 📥 Student Import
* 📤 Student Export
* 📊 Admin Dashboard
* 🎓 Student Dashboard
* 👨‍🏫 Teacher Dashboard
* 👪 Parent Dashboard

## 🛠️ Technologies Used

* Django
* HTML

* JavaScript
* SQLite

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Shxradverma/student-result-management-system.git
```

### 2. Open the project directory

```bash
cd student-result-management-system
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install django
```

### 6. Apply migrations

```bash
python manage.py migrate
```

### 7. Run the development server

```bash
python manage.py runserver
```

Open the application in your browser using the local address displayed by Django.

## 🎯 Project Objective

The objective of this project is to provide a centralized platform for managing student information, academic results, attendance, fees, teachers, and notices.

It reduces manual record management and makes academic information easier to organize and access.
